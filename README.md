# Library Management System

A simple Library Management System developed using Python and SQLite for managing books and issued-book records.

## Features

* Add books
* Search books
* Delete books
* Issue books
* Return books
* View issued books

## Technologies Used

* Python
* SQLite

## Project Description

This project was developed to understand how Python applications can interact with a database. SQLite is used to store and manage book and issued-book information.

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code or another Python editor.
4. Run `main.py`.

## Learning Outcomes

* Python programming
* SQLite database operations
* CRUD operations
* Working with structured data
* Building a simple database-driven application
